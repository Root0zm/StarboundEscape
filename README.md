# Starbound Escape

A 2D action roguelike built with Unity as a student learning project.
Try it out at: root0zm.itch.io/starbound-escape
Password to access: Root0zm

## Gameplay
- Fight enemies and bosses across multiple stages.
- Collect and stack items to strengthen your character.
- Survive increasing difficulty and reach the final stage.

## 
Unity 6 · C# · UI Toolkit

## Notes
Some third-party assets are excluded from this repository, so the project may not run correctly after cloning. Artwork and audio belong to their respective owners.
